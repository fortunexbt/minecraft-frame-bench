# Capture protocol

How to get captures that can be compared with each other.

## Setup

Use disposable worlds with recorded seeds and normal ticking and mob AI. Use Creative for protected camera tests, and label spectator flight as such. Warm the scene and the shader before arming. Don't download, build, browse or screen-record during a capture, and check background CPU, memory pressure and swap before starting. Keep the control layer identical between compared runs.

## Routes

`\m4pan <run-id> [seconds] [yaw] [pitch] [time of day] [weather]` defaults to 60 s, yaw 0, pitch 5, time 6000 and clear weather. Weather is `clear`, `rain` or `thunder`.

`\m4move <run-id> <seconds> <mode>` sets time 6000 and clear weather, then holds forward from the current position and orientation. `sprint`, `fly` and `swim` also hold sprint. `shuttle` alternates 4 s walking legs and 2.8 s sprinting legs, turning 180 degrees between legs, and needs a verified clear straight path of at least 24 blocks. Movement is a timed input pattern with no pathfinding.

Both scripts record sampled positions and world state to `<run-id>-route.json`, and `m4move` runs `/tick query` at the end. Tick progression checks the simulation and says nothing about the GPU.

## Comparisons

Restore the same stopped-world snapshot before each fresh-terrain run. Never copy an active save, downgrade a world, or compare a fresh route against terrain generated by the previous candidate. Record the actual framebuffer size, settings, background state and whether the route finished. Repeat runs and alternate the candidate order. Keep invalid captures, and don't drop valid runs because they look bad.

`capture.py` records `--min-idle` with the run, because another machine may need a different threshold. The gate can't prove that no background work interfered, so read the saved process samples too.

## Cleanup

Remove the agent JVM argument and the Minescript scripts from a daily-use instance, then check it still starts through its normal launch path. `build/controller release` releases any movement keys the helper is holding.
